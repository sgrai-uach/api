# Registro y Gestión de Defectos de Integración y Regresión (Post-Merge en Rama Develop) — SGRAI

Este documento formaliza el registro, seguimiento, trazabilidad y certificación del ciclo de vida de los defectos detectados durante las auditorías técnicas de **integración continua post-merge y pruebas de regresión** en la rama principal `develop`, tras la aprobación e integración de los Pull Requests (PRs) correspondientes a las historias de usuario del Sistema de Gestión de Recursos para Atención de Incidentes (SGRAI), de la Dirección de Gestión de Riesgos de Desastres de la Municipalidad de Valdivia.

El marco metodológico y documental aplicado se ajusta a los estándares internacionales **IEEE 829 / ISO/IEC/IEEE 29119**.

## 3. Casos de Prueba de Integración Vinculados (CP-INT)

Los defectos registrados fueron identificados mediante la ejecución sistemática de los siguientes procedimientos de verificación sobre la rama `develop`:

* **`CP-INT-00 (Setup BD)`:** Verificación de inicialización limpia de base de datos PostgreSQL + PostGIS y aplicación secuencial de migraciones Kysely (`npm run db:migrate`).
* **`CP-INT-01 (Build API)`:** Verificación estricta de tipado (`npx tsc --noEmit`) y compilación productiva del backend (`npm run build`).
* **`CP-INT-02 (Contrato OpenAPI)`:** Validación de unicidad de rutas, sincronización SemVer, esquemas Zod y seguridad en `GET /openapi.json`.
* **`CP-INT-03 (Lint)`:** Ejecución de análisis estático de código y reglas ESLint (`npm run lint`) en `sgrai-api` y `sgrai-web`.
* **`CP-INT-04 (Tests Unitarios e Integración)`:** Ejecución integral de la batería automatizada con Vitest (`npm test`).
* **`CP-INT-05 (Auth Endpoints Protegidos)`:** Validación de flujo de autenticación JWT Bearer, proyección de usuario activo y guardias RBAC.

## 5. Guía de Reproducción Técnica de Defectos para Desarrollo

### `BUG-H79-API-01`: Falla de unicidad de delegado en cuadrillas activas
* **Prueba de reproducción:** Asignar el mismo `usuarioDelegadoId` a dos cuadrillas distintas consecutivas.
* **Comportamiento actual:** Se crean ambas cuadrillas dejando al delegado vinculado a múltiples unidades activas.
* **Comportamiento esperado:** Debe verificarse `cuadrilla.usuario_delegado_id` con `eliminado_en IS NULL` y `estado != 'NO_DISPONIBLE'`. Si ya lidera una cuadrilla, arrojar `ConflictError` (`409`).

### `BUG-H79-API-02`: Falla de sobreescritura de roles administrativos
* **Prueba de reproducción:** Enviar `usuarioDelegadoId` con un funcionario que tenga rol `ADMIN`, `SUPERVISOR` o `ENCARGADO`.
* **Comportamiento actual:** Se ejecuta `UPDATE usuario SET rol_id = rolDelegadoId` sin restricciones.
* **Comportamiento esperado:** Validar `usuarioDelegado.rol_codigo` antes de promover. Si es administrativo, arrojar `BadRequestError` (`400`).

### `BUG-H79-API-03`: Falla en cabecera `x-user-id`
* **Prueba de reproducción:**
  ```bash
  curl -X POST "http://localhost:3000/api/cuadrillas" \
    -H "Content-Type: application/json" \
    -H "x-user-id: 00000000-0000-4000-8000-000000000001" \
    -d '{
      "nombre": "Cuadrilla Test",
      "delegacionId": "30000000-0000-4000-8000-000000000001",
      "usuarioDelegadoId": "00000000-0000-4000-8000-000000000005"
    }'
  ```
* **Comportamiento actual:** Responde `401 Unauthorized` (`"No autenticado."`).
* **Comportamiento esperado:** En `route.ts`, incluir fallback: `(await extraerUsuarioId(req)) || req.headers.get("x-user-id")?.trim() || null`.

### `BUG-H79-API-05`: Falla de análisis estático (ESLint)
* **Prueba de reproducción:** Ejecutar `npm run lint`.
* **Comportamiento actual:** 18 errores de ESLint en `src/modules/recursos-y-personal/__tests__/cuadrilla.service.test.ts`.
